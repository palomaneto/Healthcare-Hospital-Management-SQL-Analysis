# Healthcare Hospital Management SQL Analysis

## Project Overview

This project demonstrates SQL skills by analysing a hospital management database using MySQL.

The dataset contains information about patients, doctors, appointments, treatments and billing records. The objective is to answer realistic business questions that could support operational and financial decision-making within a healthcare organisation.

---

## Objectives

The project demonstrates how SQL can be used to:

- explore healthcare data
- perform data aggregation
- join multiple tables
- identify trends
- generate business insights
- support healthcare decision-making

---

## Dataset

Source:

Hospital Management Dataset (Kaggle)

Tables included:

- Patients
- Doctors
- Appointments
- Treatments
- Billing
